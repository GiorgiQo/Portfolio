არსებულ **პორტფოლიოს Supabase პროექტში**, SQL Editor → New query-ში ჩასვი `supabase-engagement.sql`-ის სრული შიგთავსი და დააჭირე Run. **საწყისი `supabase.sql` თავიდან არ გაუშვა.** ახალი ფაილი არსებულ ვიდეოებსა და ანგარიშებს არ ცვლის; მისი ხელახლა გაშვებაც უსაფრთხოა.

ვიდეოს ბარათზე ჩანს ლაიქის ღილაკი და კომენტარების რაოდენობა. ვიდეოს გახსნისას პლეერის ქვემოთ შესაძლებელია სახელისა და კომენტარის დატოვება. ადმინისტრატორის გვერდის ბოლოში დამატებულია კომენტარების ნახვა და წაშლა. ვიდეოს წაშლისას მისი ლაიქები და კომენტარებიც ავტომატურად იშლება.

სტუმრებს რეგისტრაცია არ სჭირდებათ. ლაიქი თითო ბრაუზერის ადგილობრივ იდენტიფიკატორზე ითვლება და განმეორებითი დაჭერით უქმდება. სხვა ბრაუზერი ან localStorage-ის გასუფთავება ახალ სტუმარს ქმნის — ეს უნიკალური ადამიანების სანდო საზომი არ არის. კომენტარები საჯაროა და სახელები გადამოწმებული არ არის. ბრაუზერის იდენტიფიკატორები საჯარო პასუხებში არ ჩანს.

კომენტარის მაქსიმუმია 1,000 სიმბოლო, სახელის — 60. ბაზა იმავე ბრაუზერის იდენტიფიკატორისთვის აწესებს 30-წამიან პაუზას და 20 კომენტარს 24 საათში. ეს მარტივი შეზღუდვებია და არ წარმოადგენს ბოტებისგან სრულ დაცვას: მიზანმიმართულ მომხმარებელს იდენტიფიკატორის შეცვლა შეუძლია. გაზრდილი სპამის შემთხვევაში საჭიროა CAPTCHA-ს სერვერული შემოწმება ან სავალდებულო ავტორიზაცია.

სტატიკური ჰოსტინგი ფაილებს არ ინახავს მომხმარებლის ატვირთვით. ამისთვის პროექტი იყენებს Supabase Auth, PostgreSQL და Storage-ს. კონფიგურაციამდე საიტი აჩვენებს აშკარად მონიშნულ დემო პროექტებს. კონფიგურაციის შემდეგ დემოები ქრება და მხოლოდ ბაზის ჩანაწერები ჩანს. ატვირთვა კონფიგურაციამდე გამორთულია; ბრაუზერის მეხსიერებაში შენახვას რეალურ ატვირთვად არ წარმოვადგენთ.

1. შექმენი პროექტი https://supabase.com-ზე.

YouTube/Vimeo ვიდეოს ჩაშენება ნებადართული უნდა ჰქონდეს. ვიდეოები და ფოტოები საჯაროა, რადგან პორტფოლიოს სტუმრებისთვისაა განკუთვნილი.

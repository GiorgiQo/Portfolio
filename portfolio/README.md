მუქი, ადაპტირებადი ვებგვერდი ქართულად, ვიდეოგალერეით, ფილტრებით, ვიდეოპლეერით, გაზიარებით და ადმინისტრატორის სივრცით.

## ლოკალურად გაშვება

საჭიროა Node.js 20 ან უფრო ახალი. დამატებითი პაკეტების დაყენება არ არის საჭირო.

```sh
cd portfolio
npm run dev
```

გახსენი http://127.0.0.1:4173. მართვის გვერდია `/admin.html`.

`npm run check` ამოწმებს JavaScript-ის სინტაქსს; `npm run build` ქმნის `dist/` საქაღალდეს.

## ვიდეოების რეალური ატვირთვის ჩართვა

სტატიკური ჰოსტინგი ფაილებს არ ინახავს მომხმარებლის ატვირთვით. ამისთვის პროექტი იყენებს Supabase Auth, PostgreSQL და Storage-ს. კონფიგურაციამდე საიტი აჩვენებს აშკარად მონიშნულ დემო პროექტებს. კონფიგურაციის შემდეგ დემოები ქრება და მხოლოდ ბაზის ჩანაწერები ჩანს. ატვირთვა კონფიგურაციამდე გამორთულია; ბრაუზერის მეხსიერებაში შენახვას რეალურ ატვირთვად არ წარმოვადგენთ.

1. შექმენი პროექტი https://supabase.com-ზე.
2. SQL Editor-ში ერთხელ გაუშვი `supabase.sql`.
3. Authentication → Users-დან შექმენი მომხმარებელი შენი ელფოსტით და ძლიერი პაროლით. დაადასტურე ელფოსტა ან გამოიყენე ადმინისტრაციული შექმნის დადასტურების პარამეტრი.
4. SQL Editor-ში გაუშვი:

```sql
insert into public.portfolio_admins (user_id)
select id from auth.users where email = 'qoridzegiorgi48@gmail.com';
```

5. `config.js`-ში ჩაწერე Project URL და **publishable / anon** საჯარო გასაღები. **არასოდეს ჩაწერო service_role / secret გასაღები ან ანგარიშის პაროლი.**
6. Authentication-ის პარამეტრებში გამორთე ახალი მომხმარებლების რეგისტრაცია (ეს პორტფოლიო ერთ მფლობელზეა გათვლილი). RLS ნებისმიერ შემთხვევაში ზღუდავს ცვლილებებს მხოლოდ `portfolio_admins` სიით.
7. გახსენი `admin.html`, შედი და ატვირთე ნამუშევრები. ფაილები პირდაპირ Supabase-ში იტვირთება, ჰოსტინგის API-ს ზომის შეზღუდვის გარეშე. სესია ინახება მხოლოდ გვერდის მეხსიერებაში; გვერდის განახლების შემდეგ ხელახლა შედი.

მხარდაჭერილია MP4 / WebM მაქსიმუმ 50 MB, გარეკანი JPG / PNG / WebP მაქსიმუმ 10 MB. უფრო დიდი ვიდეოებისთვის გამოიყენე YouTube/Vimeo ბმული. დიდი ვიდეოს ქსელური შეცდომისას საჭიროა ატვირთვის თავიდან დაწყება; resumable ატვირთვა ამ ვერსიაში არ არის. რეკომენდებულია H.264 MP4 ბრაუზერებთან თავსებადობისთვის. YouTube/Vimeo ვიდეოს ჩაშენება ნებადართული უნდა ჰქონდეს. ვიდეოები და ფოტოები საჯაროა, რადგან პორტფოლიოს სტუმრებისთვისაა განკუთვნილი.

გამოქვეყნება და წაშლა მართვის გვერდიდან მუშაობს. არსებულ პროექტს შესაცვლელად წაშლი და თავიდან დაამატებ. შენახვისა და ტრაფიკის ლიმიტები შენს Supabase გეგმაზეა დამოკიდებული.

## Vercel-ზე განთავსება

1. ატვირთე ეს პროექტი შენს GitHub რეპოზიტორიაში.
2. Vercel-ში Import Project → აირჩიე რეპოზიტორია.
3. Root Directory: `portfolio` (თუ რეპოზიტორიაში ამ საქაღალდეს ტოვებ). თუ მხოლოდ შიგთავსს ატვირთავ, დატოვე ძირეული საქაღალდე.
4. Framework Preset: Other; Build Command: `npm run build`; Output Directory: `dist`.
5. Deploy. მიღებული საჯარო HTTPS ბმული შეგიძლია გაუზიარო დამკვეთს.

## GitHub Pages-ის ალტერნატივა

გაუშვი `npm run build`, შემდეგ `dist/`-ის შიგთავსი მოათავსე Pages-ისთვის არჩეულ ფილიალში ან გამოიყენე Actions-ის static-pages workflow. ყველა ლოკალური მისამართი შედარებითია, ამიტომ `/repository-name/` ქვეკატალოგშიც მუშაობს. Supabase კვლავ აუცილებელია ვიდეოების ასატვირთად.
